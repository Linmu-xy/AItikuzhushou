## 未作为本次准确率结论的项目

- 扫描件 OCR 准确率需要甲方指定扫描样本及评分表；当前已具备 OCR/视觉模型接入路径，但未将模拟数据结果当作准确率基线。
- 七类真实格式覆盖率和 100 页向量化耗时，需要在目标服务器规格与甲方验收样本到位后执行正式压测并记录基线；任务强制中断恢复已在本机验证。
- 前端当前由 Vite 本地服务提供；部署时按 `docs/windows-deployment.md` 配置反向代理、TLS、备份和服务守护。

## 任务反馈约定

- 文件上传、文档解析、职业标准解析、AI 命题和 Excel 导出均返回持久化任务 ID；前端提交后立即回查，只有服务端确认才显示为已受理。
- 页面弹窗展示业务状态码、任务编号、阶段、百分比和已处理/总量，支持最小化、刷新恢复、取消、失败重试和完成后跳转。
- AI 命题弹窗额外展示计划、通过、拒绝和耗尽数量；不足时显示 `QUESTION_COUNT_MISMATCH`，同时提供“继续补题”和“导出不完整题库”。
- 导出弹窗依次展示 `QUESTION_SNAPSHOT_CHECKING`、`COUNT_VALIDATING`、`EXCEL_WRITING`、`EXPORT_VALIDATING`、`FILE_STORING`，完成后显示 `DOWNLOAD_READY` 或 `PARTIAL_EXPORT_READY`。
- 题目审核页展示 AI 草稿、人工通过、驳回和锁定数量；编辑形成新版本，审核历史记录操作人、时间、说明与快照。
- Excel 导入采用“选择文件 → 校验并预览 → 确认导入”两阶段操作，校验阶段不写入数据。
- HTTP 错误统一返回 `statusCode`、`message`、`httpStatus`；模型额度不足、模型不可用和质量门禁失败使用独立业务状态码。
