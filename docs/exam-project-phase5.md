# 命题项目：第 5 阶段开发说明

本阶段完成“生成前命题依据冻结”。项目不再只是保存配置，而是能够在生成前检查来源完整性，并创建不可变的来源、样题/模板结构和 CAD 人工确认事实快照。

## 已实现

- 新增 Flyway V39：`exam_project_evidence_snapshots`。
- 新增 `POST /api/exam-projects/{id}/generation-preparation`，执行生成前检查并创建版本化快照。
- 新增 `GET /api/exam-projects/{id}/generation-preparation`，查看项目最近一次依据快照。
- 标准驱动/融合驱动必须关联职业标准，且职业标准必须人工确认。
- 资料驱动/融合驱动必须包含任务书、样题和试题模板角色。
- 文档必须完成解析；系统会记录文档版本指纹、解析分块数量和样题/模板结构提示。
- 已选择的三维模型/工程图必须完成 CAD Worker 读取，并且至少有一项人工确认、允许出题的事实或图纸标注。
- 快照只保存来源版本、结构提示和已确认事实，不把整份受版权保护的原文直接展示给项目列表。
- 快照即使处于 BLOCKED 也会保留，便于老师定位问题和审计；只有 READY 快照可进入下一阶段生成任务。
- 项目配置页新增“检查并冻结命题依据”区域，显示来源数、确认事实数、样题数、模板数和阻塞原因。

## 使用流程

1. 在“命题项目”中保存项目配置并关联资料。
2. 完成文档解析、职业标准确认和 CAD 事实确认。
3. 点击“检查并冻结命题依据”。
4. 若显示 BLOCKED，按页面列出的资料角色、解析或人工确认问题处理后重新冻结。
5. 显示 READY 后，下一阶段将基于该快照建立变式生成任务。

## 下一阶段边界

下一阶段才会把 READY 快照接入变式卷任务：根据样题结构、模板分值、教师要求和已确认 CAD 事实生成题型/难度计划，并沿用现有人工审核与质量门禁。原有职业标准题库生成接口继续保持不变。
