# 命题项目：第 4 阶段开发说明

本阶段将首页的“标准驱动 / 资料驱动 / 融合驱动”入口落成可保存的命题项目配置。项目配置与原有职业标准、知识库、题库任务、资料组卷页面通过引用关系连接，不修改原有业务数据。

## 已实现

- 新增 `exam_projects` 和 `exam_project_sources` 数据表，Flyway 版本为 V38。
- 新增项目创建、查询、修改和资料关联接口：`/api/exam-projects`。
- 支持文档资料和 CAD 资料按角色关联：职业标准、任务书、样题、模板、工程图、三维模型、其他资料。
- 支持标准驱动、资料驱动和融合驱动三种项目模式。
- 支持任务要求、变式卷数量、简单/中等/困难比例和题型分值结构保存。
- 强制确认资料使用授权后才能保存项目。
- 项目资料记录文件版本哈希，后续生成阶段可以据此冻结来源版本。
- 项目资料与知识库隔离，不能跨知识库关联文档或模型。

## 本地验收

登录后进入“总览 → 开始融合驱动”，或左侧“工作台 → 命题项目”。

建议依次验证：

1. 选择知识库和命题模式。
2. 选择已有文档、模型或工程图，设置资料角色。
3. 填写题型、题量和分值，确认难度比例合计为 100%。
4. 勾选授权确认并创建项目。
5. 修改资料角色、移除资料后再次保存，确认项目资料列表同步更新。

## 下一阶段边界

本阶段只保存项目配置和来源版本，不生成题目。后续阶段将使用项目冻结的来源、已确认模型事实、样题结构和分值结构建立变式生成任务，并继续经过人工审核后才能导出。
