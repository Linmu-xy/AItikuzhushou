# 开放命题 V2 重构与实测报告

日期：2026-09-26。代码已部署到本地服务。重构范围是当前知识库命题主入口，职业标准工具与历史计划继续兼容。

## 结论先行

新链路已落地：所选资料的完整归纳 → 领域/能力画像 → 中立任务规划 → 自主命题 → 盲解 → 反例与质量审查 → 最多一次定向修订 → 教师审核。命题、盲解、审查都可以按需调用真实搜索，计算题可调用纯数值计算工具。

这轮验证证明了工程链路可运行、能保留原题恢复审查、不会自动批准或导出未审核题目；没有证明题质已经稳定达到正式考试要求。真实样本仍有错误答案、评分缺口、过度泛化和模型审查误放行。不要将“AI审查通过”理解成“已经正确”。

本次遵循出题优化技能的真实样本/真实用量验证，并用 rewrite-plan 的多文件边界隔离旧链路；没有清空历史项目，也没有人工改好样题后冒充模型输出。

## 为什么原来容易显得呆板

1. 每题绑定文档段落/页码，把选到的材料当作答案范围，迁移任务被压缩成复述。
2. 作者只能收到长资料前部，尾部内容丢失；材料中的数字与措辞形成强烈锚定。
3. 规划提前决定具体情境、错误配置与结论，后续模型只能给既定答案补故事。
4. 审题直接看作者答案，容易顺着解释认可；算术正确又会掩盖公式前提、物理方向和评分错误。
5. 联网只发生在规划阶段，作者/审题发现新疑问后不能主动查证；失败与质量不合格混在一起。

对应改动、模型路由、预算、恢复与隐私边界见 [设计说明](open-assessment-v2.md)。不再要求通用题附知识库出处，原图依赖题仍必须给考生实际图片。

### 一个明确的审题盲区

R2-2的盲解只说“制品偏大应减小型腔尺寸”，这一步合理；作者进一步写成“去除材料将型腔改小”，审题却一并通过。这不是算术问题：针对形成外轮廓的空腔，去除其边界金属会扩大空腔，而非缩小。说明仅对比最终数字或宏观结论不足以核查新增的工艺解释。

R3-2又把共用基准与误差累积简单关联。作为核查参考，Autodesk 官方说明基线尺寸以共同起点测量，可以减少链式尺寸累积误差。因此“共同基准必然导致累积误差”不能作为泛化判据；实际是否合适需结合功能与公差设计。参见 [AutoCAD尺寸说明](https://help.autodesk.com/cloudhelp/2026/ENU/AutoCAD-OnBoarding/files/ACD_FOUNDATIONS_MAIN10.html)。

拔模角会作用于零件实体几何，不能仅因为它与成型工艺有关就推导“不得在产品尺寸中控制”。这是结合模型原答案和 [Autodesk拔模教程](https://www.autodesk.com/learn/ondemand/curated/part-modeling-fusion-360/5zb4vIPJRJ28MKMNt0ctYv) 的审查推断，不是关于某一具体标准条文的替代解释。

### 根据实测追加的修复

- 以领域画像替代可照抄的原文参数清单，原图题仍保留真实素材。
- 作者收到题位分值，要求小问总分由明确给分点构成；规划保持中立，不预设某做法错误。
- 新增最强反例/替代方案检查，不仅要求几个PASS或自评分；该检查也会漏判，见上表。
- 开放题主动要求识别未知条件时不再被 `ambiguities` 非空机械否决；真正不可答与封闭题歧义仍拦截。
- 增加纯数值验算、百分比定义/近似前提检查、协议恢复与失败保留。
- 增加原题重审、历史审查轨迹与人工版本保护。R3先因旧歧义门禁拒绝、修复后重审，两次记录均保留；没有直接修改数据库把拒绝改通过。

最后两题的作者输出早于最后一轮中立规划/评分文案更新；最后一轮只重审原题。因此不能声称最后的规划与作者提示已完成新的实盘效果对比，它们已通过代码/回归测试。

## 如何使用与剩余边界

1. 在知识库命题项目中确认资料与题量，创建新的题位计划。旧V1计划不会被偷偷改写，必要时重新创建计划进入V2。
2. 可开启“允许 AI 按需联网”。明确关闭时不搜索；开启后由作者/盲解/审查按需要请求，设有费用与隐私保护上限。
3. 候选题进入教师审核。等待审题或AI自动拒绝、尚未人工处理的题可仅重审，不必重新付费命题。
4. 只有人工通过的题能进入导出流程。不要直接采用本报告指出有实质问题的样本。

仍需验证：多学科真实材料、学生试测、实测区分度/难度/评分一致性、大型200题规划、不同模型之间的审查对照、完整浏览器审核业务。使用同一基础模型分别扮演作者和审查者仍有相关性错误；搜索摘要和模型反例也不是权威结论。
