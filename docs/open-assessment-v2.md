# 能力导向开放命题 V2

## 目标与实际边界

本次不是取消正确性要求，而是取消“答案必须在所选知识库段落里出现”的限制。知识库用于识别学科、学习阶段、核心内容与真实素材；模型可以使用稳定学科知识、自拟明确条件、迁移案例。真实标准/实时信息/精确图纸事实仍需核实，不以虚构事实制造唯一答案。

命题框架参考 [ETS 的能力—作答证据—任务设计](https://www.ets.org/research/policy_research_reports/publications/report/2011/imbu.html) 和 [CMU 的考核目标对齐原则](https://www.cmu.edu/teaching/assessment/basics/alignment.html)。不同学科可选择解释、计算、实验、证明、表达或操作，不强迫所有题套职业处置情境。基础理解题不是天然无效；难度来自所测能力，不是题干长度。

## 新链路

完整资料归纳 → 能力与作答表现规划 → 自主命题 ↔ 搜索/算式工具 → 不看作者答案的独立作答 ↔ 工具 → 语义审查 → 必要时修订一次并重新作答/审查 → 教师审核。

### 1. 从整库理解学科，不逐段分配题目

- 新计划版本为 `OPEN_ASSESSMENT_V2`。`documentId` 可为空，只有实际使用某页素材才绑定资料；依赖原图的题目必须附真实图片。
- 大资料分段归纳后汇总，覆盖尾部主题；取消“只给作者前12000字符”的截断。
- 新路径取消每题自动检索6段文本作为答案限制。完整归纳的学科背景、任务方向与用户要求传给命题模型。
- 实测发现只放宽提示词仍易复用原文参数，因此将 `domainBrief` 单独提炼为概念、方法与学习阶段。通用迁移题的作者主要接收领域画像，而不是可照抄的原文参数清单；明确依赖资料/图片的题仍能接收原始整库上下文和附图。规划不再预填题目数值、错误配置或解题公式。
- 智能题型可自主选择题型和分值；用户明确指定的难度分布仍按最大余数法分配，固定题型配置继续生效。

### 2. 工具是模型按需调用的能力

- `SEARCH`：命题、独立作答、审查任一阶段可以请求。先提炼公开主题，再调用 DeepSeek Anthropic `web_search`；返回真实检索结果、URL和时间。
- 新知识库项目默认允许按需搜索；显式关闭仍有效，历史项目不修改开关。只把提炼后的短主题发送到搜索工具，不发送资料全文。模型脱敏与格式校验属于风险减缓，不等同于企业级 DLP。
- 每题最多3次检索请求；单次生成执行共享最多 `min(12,max(2,题量×2))` 次实际搜索，查询缓存仅在当前任务内共享，不跨用户。人工点击“仅重试审题”另给2次搜索预算。进程恢复可能重复未落盘的调用。
- 每阶段最多3次工具请求后必须完成，不允许无限工具循环；关闭、预算不足、无结果、上游失败均显式传回。失败结果不能冒充已核实事实。
- 搜索响应必须包含真实 `server_tool_use`、`web_search_tool_result`、安全URL及完整回答；不把模型凭空给出的链接当成搜索成功。
- 检索服务显式 `thinking: disabled`，命题检索上限3000输出token，摘要最多4条/500字。原因：实测旧请求未指定思考模式，检索预算会被推理消耗；[DeepSeek 官方说明](https://api-docs.deepseek.com/guides/thinking_mode/) 指出默认开启思考。
- `CALCULATE`：16位有效数字的纯数值四则运算，每次1–6个表达式。禁止变量、函数、任意代码、文件与网络访问。计算题独立解题必须真实调用，不能只声称“已验算”。计算工具只能证明数值结果，不能证明公式适用。

### 3. 独立作答与实质审查

盲解输入采用允许列表，只有题型、题干、选项与实际附图。不会传作者答案、解析、评分标准、能力任务、知识库摘要或作者检索轨迹。作答者可以主动检索专业原理。

审查再比对作者与盲解，检查：正确性、条件充分、能力目标对齐、评分可执行、题间差异、关键事实、独立答案一致性，以及选择题逐项合理性。任何必需检查缺失都不通过。封闭题盲解与答案不一致会阻断；开放题允许合理等价表达，不做答案字符串硬匹配。

开放任务可能故意考查条件不足或方案边界，`ambiguities/unresolvedFacts` 非空本身不再自动否决这类题；独立作答明确不可作答、审查条件不充分或关键事实不成立仍然阻断。选择/判断题的歧义仍是硬阻断。修复来自真实 CAD 开放题的误判，而非通过降低统一分数线放行。

规划要求中立，不预设某种工程做法错误。审查必须给出最强反例/替代方案及其是否成立、是否被评分误排除；缺少这项检查或确实排除了合理答案会阻断。该机制要求可核查的反驳内容，不证明模型一定能找到反例。

取消 V2 中的词汇重合、题干长度、绝对词黑名单和固定75/35分数门槛。保留结构、答案格式、真实附图与评分完整性检查。AI给出的“区分度分数”只是估计，不是测量得到的统计区分度。

另外要求审查“无学科知识挑战”：能否靠唯一异类数值、长选项或词句匹配破解？该项必须明确返回布尔判断；中高难题被识别为可凭表面线索作答时阻断，而不是仅看自评分通过。上游偶尔只返回推理而无可见正文时，审查阶段只针对这种明确协议错误做一次非思考恢复；不为额度/网络错误自动追加调用。

百分比的基准、近似模型、单位与有效数字必须清楚；不同定义的公式不能因为舍入后相同就被说成等价。内部 `basis` 描述能力表现、典型误解、模拟条件与关键命题，不向考生暴露这些内部字段。

### 4. 可恢复、可审核

- 结构或语义失败合计最多一次定向修订，不对无关题位重跑。修订后重新独立解题和审查。
- 审题服务不可用保留原题为 `REVIEW_PENDING`，不重新命题。页面“仅重试审题”支持等待审题或 AI 自动拒绝的候选题；不改变题目正文、版本、生成次数，保留历次 AI 审查记录。人工编辑/审核过的题不允许此操作；保存时校验原状态、版本和审核人，防止慢请求覆盖并发人工修改。重审仍消耗额度，通过后仍需教师审核，不自动批准。
- 恢复任务只继续 `PLANNED/GENERATING`，不覆盖待人工审、已通过、已编辑或已失败的历史题目。
- 每道题的 `design_json` 保留工具结果、独立解答、审查和首轮修订反馈。对外题目剔除 `_assessment*`；工具URL不强制出现在题面。
- 所有阶段使用已有实际 usage 计量，包含失败调用。输出token预算是上限，不等于实际消耗。
- 并发实测曾复现：规划事务持有额度行锁，另一个线程持有 `reserve` Java锁并等待该行，规划再次申请额度时形成交叉等待。额度的预留/结算/事件改为 `REQUIRES_NEW` 独立短事务；并发测试在外层规划事务未提交时验证另一个额度申请能完成。该修复也避免实际调用记录随规划事务失败而回滚。

## 模型调用表

| 阶段 | 模型路径 | 预算/思考 | 触发 |
| --- | --- | --- | --- |
| 学科归纳 | 普通文本 | 2200 / low | 长资料分段时 |
| 原图概览 | 已配置视觉 | 900 / 非思考 | 代表页与计划需要的图片 |
| 考核规划 | 普通文本 | 12000–16000 / high | 每个新计划一次 |
| 命题 | 普通文本，深度模式使用 questionModel | 12000 / high | 每题，最多修订一次 |
| 盲解 | 普通文本 | 8000 / high | 每个有效候选 |
| 审查 | 普通文本 | 6000 / low | 盲解完成后 |
| 图文命题/盲解/审查 | 已配置视觉 | 5000 / 非思考 | 题目有实际附图 |
| 查询脱敏 | 普通文本 | 350 / 非思考 | 每次查询请求 |
| 实际搜索 | Anthropic deepseek-flash | 3000 / 非思考 | 模型主动请求且预算允许 |
| JSON语法修复 | 普通文本 | 5000 / 非思考 | 非空且≤24000字符的非法JSON，每个响应最多一次 |

每次工具返回后会增加一次该阶段的模型调用。检索失败不自动无限重试。文本与图片路径使用真实配置模型；同一个基础模型分角色仍可能产生关联性错误，不能宣称是独立专家验证。

## 兼容与未验证范围

旧 V1 计划、职业标准链路、人工审核、导出结构保持兼容；新流程针对当前知识库命题主入口，职业工具未一并切换。未新增数据库迁移，不删除或覆盖既有项目。

通用知识不必逐条联网核验，因此不能保证每个事实正确。搜索摘要不是完整文献审查。真实考试仍需专家审题、学生试测，计算难度/区分度/干扰项表现与评分一致性。当前小样本只能验证链路与初步题质，不能宣称测评效度已获证实。大型200题规划、实际学生试测和多学科真实API样本不在本轮验证覆盖内。

实测脚本：`scripts/Test-OpenAssessmentV2.ps1`。第一次用 `-Mode Create`，读取用 `-Mode Status/Collect`；`-Revision 2` 创建单独回归记录，默认拒绝重复创建同一个付费测试。`-Mode RetryReview` 仅重审该测试批次尚未人工处理的候选题（有 API 消耗），保存重审前的历史记录。

验证结果与尚存缺陷见 [实测报告](open-assessment-v2-validation.md)。自动化测试通过不等同于题目已经达到正式考试质量。
