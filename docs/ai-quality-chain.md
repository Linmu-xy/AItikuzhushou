# AI 证据化命题链路

## 当前：能力导向开放命题 V2

新建知识库计划现在使用 `OPEN_ASSESSMENT_V2`，以学科能力和可观察作答表现为中心，不再给每题强制绑定知识片段。2026-09-27 当前执行版本为 `OPEN_ASSESSMENT_V2_3_1`：按题目风险分配思考，数值随最终答案本地校验，空/截断有一次受控恢复并复用同题成功恢复路径，评分合计和盲解异议有明确校验；资料概览可短期按用户/内容/模型缓存。重审不重复传入历史审查记录。命题、盲解和审查仍可按需搜索，语义失败最多修订一次，不自动批准题目。完整架构、实际模型调用、兼容边界与局限见 [开放命题 V2](open-assessment-v2.md)。下文保留 V1 与职业旧链路的历史记录，不是新知识库流程的默认约束。

## 历史：知识库开放命题 V1

知识库文档先形成整库语境；有原图的代表页面即使已有 OCR 文本也先做视觉概览，避免只凭转写文字规划识图题。规划模型可以使用稳定的通用学科知识并构造题干明示的工作条件，知识库用于限定主题和提供真实素材，不再要求答案逐字落在某个检索片段中。新任务记录 `OPEN_ASSESSMENT_V1`、整库语境、题位的可作答说明和所需材料；旧任务按原快照继续执行。

规划阶段只设能力、任务轮廓和可作答条件，不预写题干、选项或答案。正式写题按批看到整库语境与相关材料，图像题同时看到原图和可选局部放大。模型输出题目及内部 `basis`（资料事实、通用知识、推导或联网事实）；`basis` 不出现在考生题目中。确定答案所需的精确图面数据、标准版本和网页事实必须核实；缺少待操作 DWG 等必要文件的题位被拒绝。独立审题允许合理泛化，但须拦截题干直接泄露答案、直接查表，以及答案依赖未展示原图的局部视觉事实。所有结果保持人工审核，不以 AI 自评分代替学科专家验收。

开启联网时，规划只对确实需要外部事实的题位执行定向公开检索；搜索结果随题位冻结并进入该题的写题与审题证据。搜索失败时不会把未核实的网页事实伪装成已核实结果。正式质量评价应在同一批资料和模型配置下，对比历史链路与新链路的专家盲审结果、实际 token 消耗和端到端耗时。

2026-09-26 的 CAD 小样本：3 题均进入人工审核，但其中 1 题把目标配置写入题干、1 题对未展示图纸的局部壁厚作出判断；模型自审均未发现。此结果仅证明流程可运行，不证明题目有充分考核效度。针对这两类问题已调整规划、写题和审题规则，仍需跨学科专家盲审验证。一次成功的 3 题计划及写题/审题记录共 6 次模型调用，约 28,039 输入 token、20,407 输出 token；规划阶段曾另有超时与截断失败调用，未计入该成功样本。

规则修改后又以同一 CAD 知识库回归 2 题：规划不再预写答案，图纸题也标记了需要原图；1 题进入人工审核，1 题因答案使用无法核实的细小图面数字被拒绝。该次计划、写题、审题共 9 次模型调用，约 32,529 输入 token、7,049 输出 token；多模态题的调用成本明显高于纯文本题。回归还暴露出审核输入未告知模型“原图已附”，现已补上该状态和几何不变量核查。两次小样本都不能替代专家盲审或跨学科测试。

## 处理流程

1. **逐页解析与 OCR**：PDF 逐页检测文字质量；弱文字页以 220 DPI 渲染并纵向裁片，DeepSeek Vision 按顺序转写。OCR 保留标题、条款、表格和页码，对不可辨认字符标记 `〔?〕`。
2. **解析质量门禁**：文档返回文字质量分和警告；有效正文不足或非工程图页不可辨认时保持 `OCR_REQUIRED`，禁止进入职业标准抽取。CAD 工程图页会保留原页和来源标记，但不计入正文文字质量；只有非工程图正文达到门槛后，混合资料才可继续。
3. **职业标准结构化**：DeepSeek 以 JSON 模式抽取职业名称、编码、等级，以及“职业功能｜工作内容｜技能要求｜相关知识”完整考点。考点需与原文有实质词汇重合，残句和目录项会被过滤。
4. **人工确认**：职业标准至少包含真实职业名称、一个已确认等级和五个完整考点，人工确认后才能生成细目表。
5. **混合 RAG**：每个考点同时使用中文词组匹配和 pgvector 召回，取前三个原文片段，保存定位、分块 ID 和相关度。
6. **证据适配分配**：规则层只分配题型、难度和考点。顺序题优先使用同一工作内容下具有连续编号的技能证据，避免把只有“方法和步骤”标题、没有正文步骤的考点交给模型臆造。
7. **DeepSeek AI 命题**：V3 先按批生成岗位判断蓝图，再按批生成最终五个字段；FAST 和 EXPERT 都进入独立职业审查。模型 JSON 异常、拒答或质量门禁失败只影响该题位。
8. **紧凑审查与定向修复**：审查通过题只返回分数和选择题 `optionChecks`；只有失败题才返回详细反馈并修复一次。审核超时、空响应或非法 JSON 只重试审核并将候选题标记 `REVIEW_PENDING`，不会再次生成；用户显式重试时先执行审核专用流程。已通过题位不会重复生成，服务重启后从数据库恢复题位状态继续执行。
9. **交付门禁**：逐题检查题型结构、答案格式、岗位情境、职业区分度、外行可猜性、内容非模板化、解析完整、考点与证据一致性和重复题干。全部满足计划数量时状态为 `SUCCEEDED`；连续修复仍不足时状态为 `FAILED / QUESTION_COUNT_MISMATCH`，不会用模板题凑数。
10. **可追溯导出**：导出为独立异步任务，先校验任务快照与计划数量，再生成 Excel、回读校验并写入 MinIO。完整文件状态为 `DOWNLOAD_READY`；不完整文件状态为 `PARTIAL_EXPORT_READY`，工作簿“交付说明”页记录计划数、实际数和风险说明。

## 生产配置

生产配置默认启用：

```text
APP_OCR_ENABLED=true
APP_AI_STANDARD_EXTRACTION_ENABLED=true
APP_AI_QUESTION_REFINEMENT_ENABLED=true
APP_AI_QUESTION_BATCH_SIZE=3
```

关闭模型命题仅用于离线开发诊断；生产任务会在 `request_json.qualityMode` 中记录 `MODEL_GROUNDED`。

# 2026-09-27 V2.3 命题策略与审查契约优化

- 实际运行版本 `OPEN_ASSESSMENT_V2_3_1`；冻结计划版本仍为 `OPEN_ASSESSMENT_V2`，兼容已有计划。
- V2.3.1追加：计算题的数值/模型歧义不能仅靠评分容差闭合，需题干依据或明确要求条件性作答，否则待复核。
- 命题改为短通用原则 + 当前题型策略。允许超出知识库迁移、按需联网、识图；不强加固定认知比例。
- 稳定工具协议移到动态输入前；删除不相关题型要求和带 CAD 收缩率倾向的工具示例。不宣称已测得缓存命中提升。
- 审查响应缺字段、证据摘录无效或结构化结果与文字结论矛盾，保留题目到 `REVIEW_PENDING`，不自动重写，也不自动通过。
- 明确 FAIL、NEEDS_CHANGE、独立答案分歧、排斥合理解等实质失败继续阻断并允许既有的一次修订；人工审核边界不变。
- `evals/question-quality` 运行生产 Java 门禁的固定案例；离线回放不调用模型，不能当作学科质量验收。
