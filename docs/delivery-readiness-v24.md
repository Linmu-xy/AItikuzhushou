# V24 交付完善记录

## 本次已实施

- 账号总存储配额：10GB 现在按用户账号汇总执行；新增知识库不会突破个人总额度。
- 回收站：知识库删除进入回收站，保留 30 天，可由原用户或管理员恢复；常规列表不再显示已回收内容。
- 临时分享：可创建无密码、默认 24 小时的知识库临时分享链接；可提前撤销。公开链接只返回分享所需的知识库摘要，不返回用户、密钥或内部任务数据。
- 细目表 Excel 往返：支持导出 `.xlsx`，编辑后通过接口重新导入，并重新校验题位数量、题型、难度和考点映射。
- 九种正式题型：单选、多选、判断、填空、简答、计算、论述、案例分析、综合题。
- 考点映射规则：客观题 1 个；简答/计算 2 个；论述/案例/综合 3 个。细目表保存和质量门禁均执行该规则。
- Windows 启动脚本：MinIO 首次初始化改为最长 20 秒的可用性轮询，避免首次启动的误报失败。

## 已验证

- 后端自动化测试：23 项通过。
- 前端 TypeScript 编译与生产构建通过。
- PostgreSQL 生产库成功从 V23 升级至 V24。
- PostgreSQL、MinIO、Redis、后端 8080、前端 4173 健康检查通过。
- 临时分享创建、公开读取、撤销；细目表 Excel 导出均完成真实接口冒烟验证。
