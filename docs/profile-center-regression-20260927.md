# 个人中心改版与回归检测

日期：2026-09-27。范围：个人中心界面、非手机号/邮箱问题修复，以及现有业务链路回归。

## 界面结果

个人中心改为账户概览与编辑区域两栏。概览集中展示身份、知识库空间及今日额度；编辑区域使用「个人资料 / 助手偏好 / 账户安全」三个分区。低频的用户名、密码、联系方式修改默认收起。颜色、字体、按钮与工作台保持一致；去除旧个人中心的重复额度面板及无用技术字段展示。

支持保存位置的成功/错误反馈、分区间保留编辑草稿、头像预览与取消、头像加载失败回退、密码显示/隐藏、键盘方向键切换分区，以及小屏幕上下排列。手机号和邮箱的接口、验证与发送逻辑未做修复或扩展，只重新组织了页面位置。

## 已修复的问题

| 问题 | 修复与验证 |
| --- | --- |
| V47 在 H2 不支持表达式索引，导致 51 项集成测试无法启动 | 按数据库选择 V47 脚本，H2 使用生成列建立等价唯一索引；PostgreSQL 脚本内容和校验值保持不变。47 项迁移成功，原有集成测试恢复。 |
| 修改密码后其他登录会话仍然有效 | 会话校验移到身份读取完成后执行；回归验证旧会话返回 401、当前会话续接、新密码可登录、旧密码不可登录。 |
| 用户名含首尾空格时，更新成功却无法续接会话 | 使用服务端已规范化的用户名建立新会话；扩展原有改名测试覆盖带空格输入。 |
| 移除头像时存储清理失败，界面错误地显示移除失败 | 账户头像修改提交后，将旧文件清理作为单独处理；模拟存储异常验证仍返回已移除的账户资料。清理失败会记入日志，旧对象可能留待清理。 |
| 超长密码触发 BCrypt 长度异常 | 前后端限制 UTF-8 编码后最多 72 字节，并给出明确提示；回归覆盖超长中文密码。 |
| 保存资料/偏好会清空其他未保存字段 | 拆分字段同步，保留其他分区草稿；浏览器实际验证。 |
| 保存头像或显示名称会覆盖当前对话的临时偏好 | 仅在账户的默认偏好真正变化时同步助手设置；浏览器验证临时「快速、关闭联网」不会被资料保存覆盖。 |
| 新建项目忽略账户的联网默认偏好 | 项目初始化接收账户默认值；显式对话草稿和已有项目保存的设置优先。 |
| 个人中心被旧全局 aside/header 样式污染 | 使用独立作用域及显式背景/布局，清除深色底、标题横排等继承冲突；桌面和窄屏截图复核。 |
