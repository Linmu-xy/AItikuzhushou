# 命题项目第 6 阶段：变式题位计划

## 本阶段交付

第 5 阶段冻结的命题依据现在可以转换为一份可审阅的多套变式卷题位计划。计划会记录：

- 使用的证据快照 ID、版本和指纹；
- 套卷数量、每套题量和总题量；
- 每个题位的题型、题号、难度和分值；
- 本次计划可使用的资料角色。

题位按照教师填写的分值结构排列，同一题型连续放置；同一题型内按简单、中等、困难顺序排列。小题数量不能被难度比例整除时，系统使用最大余数分配，保证题量和分值结构不变。

## 使用边界

本阶段只建立持久化计划，不调用模型、不生成题干、不写入原有 `generation_jobs` 和题目表。计划必须引用状态为 `READY` 的命题依据快照；项目配置、资料版本或模型事实发生变化后，旧快照会失效，必须重新冻结并创建新计划。

接口：

- `GET /api/exam-projects/{projectId}/variant-generation-tasks`：查看项目历史计划；
- `POST /api/exam-projects/{projectId}/variant-generation-tasks`：为当前 READY 快照创建或复用计划；
- `GET /api/exam-projects/{projectId}/variant-generation-tasks/{taskId}`：查看指定计划。

## 下一阶段入口

下一阶段将以计划中的单个题位为最小任务单元，组装对应的样题/模板/任务书/工程图/三维模型证据，再接入现有模型生成与质量门禁。题位计划中的题型、题量、分值和快照指纹必须作为生成请求的硬约束，教师命题要求作为可解释的变式空间。
