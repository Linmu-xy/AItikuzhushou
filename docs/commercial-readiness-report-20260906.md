## 本次发现并已修复的问题

| 编号 | 等级 | 问题 | 修复与回归结果 |
| --- | --- | --- | --- |
| QA-001 | P1 | 验证码 60 秒限流被统一映射为 HTTP 503，前端无法准确识别“稍后重试”。 | 增加 `EMAIL_CODE_RATE_LIMITED` 专用 429 状态码；新增自动化回归测试，已通过。 |
| QA-002 | P0 | 默认配置可能将本地验证码返回给调用方，不可用于生产环境。 | 默认及生产配置关闭本地验证码；生产环境未配 SMTP 时返回 `EMAIL_DELIVERY_NOT_CONFIGURED`，不返回验证码。生产接口验证无 `debugCode` 泄露。 |
| QA-003 | P1 | Windows 启动脚本读取 `.env` 时可能遗漏管理员密码，导致服务无法一键启动。 | 使用稳定的 .NET 文件读取方式解析 `.env`，修复 Windows 编码与 PowerShell 集合处理问题；标准启动脚本已重新执行并通过全部健康检查。 |

## 风险与改进建议

1. 接入真实 SMTP 后，应补充邮件送达率、退信、验证码失效和邮件服务故障演练。
2. 在独立验收环境执行 100 页解析/向量化、1000 道题生成、任务中断恢复与 30 天日志查询压测，记录硬件规格与耗时基线。
3. 用每个目标职业至少 30 道人工抽样题目评估考点映射、答案唯一性、解析依据、难度匹配和重复率；将结果写入甲方验收基线。
4. 生产部署建议采用 HTTPS、IIS 或 Nginx 反向代理、Windows 服务守护、每日数据库备份及 MinIO 备份。
5. 建议将 Maven、Node、MinIO、Redis 与 PostgreSQL 的版本固定到部署手册，升级前在独立环境执行交付包恢复和回归测试。
