# 联网搜索：助手对话与增强出题

AI 助手的“联网搜索”默认关闭，只在用户明确打开后，对当前提问调用 DeepSeek Anthropic 兼容接口的 `web_search_20250305` 工具。它复用现有 DeepSeek API Key；可用 `APP_AI_WEB_SEARCH_BASE_URL` 覆盖默认接口根地址 `https://api.deepseek.com/anthropic`。

知识库对话回答仍按本地资料的 K/A 证据生成。联网结果作为单独的“联网补充”区块保存，附实际搜索结果的网页标题和 URL；不会自动写入知识库。仅当前提问会发送到对话搜索接口，知识库正文和会话附件不会发送给搜索工具。网页内容按不可信数据处理，不能改变系统指令。

知识库出题项目另有“联网增强出题”开关，默认关闭。新建开放命题计划先理解整库资料，仅对标记为需要外部事实的题位提炼公开专业检索词并调用 DeepSeek 网页搜索；每题的检索摘要、网页标题/URL 和检索时间随计划冻结，进入该题的生成与审题上下文。网页依据需要核对版本、地区和适用条件，生成题仍需人工审核；必需的搜索失败会阻止该计划创建，不静默伪装成已验证。未标记为联网题位的任务不会为了开关而执行整套卷的泛主题搜索。当前不会自动验证网页全文，也不会自动导入知识库。旧计划仍沿用其已冻结的整卷搜索证据。

搜索响应必须同时包含实际 `web_search` 工具调用、HTTP(S) 网页结果和非空回答。对话搜索缺失或超时会显示“联网搜索未完成”，保留已有知识库回答；出题搜索失败会阻止计划创建。模型额度页面分别记录 `ASSISTANT_WEB_SEARCH` 与 `QUESTION_WEB_SEARCH`；网页检索内容可能显著增加输入 Token。

验证：`DeepSeekWebSearchServiceTest` 检查接口路径、工具参数、来源过滤、失败拒绝与 Token 记账；`TikuApplicationTests` 检查开关请求、来源持久化及搜索失败回退。真实 DeepSeek 接口已验证能返回 `server_tool_use` 和 `web_search_tool_result`。
