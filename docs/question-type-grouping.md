# 题型分组与编号规则

## 使用范围

题位计划、生成过程、质量审核列表，以及项目的 Word、PDF、Excel 试卷和答案，统一使用 `backend/src/main/resources/question-types.json` 中的顺序。前后端读取同一份配置。

默认顺序：单选题、多选题、判断题、填空题、简答题、计算题、案例题、论述题、综合题、实操任务。自定义题型放在最后，并按名称独立分组。

## 生成与审核

- 新计划先移动完整题位，再按套次从 1 连续编号。难度、分值、考核目标、文档/页码、配图与联网证据随题位一起移动。
- 智能题型先完成原有规划，再进行确定性分组，不额外调用模型。命题、独立解题、AI 审题与人工审核的门禁保持原状。
- 生成结果按预先分配的题位显示，不按模型返回时间排列。待生成和生成中的题位也显示；已生成与已审核分别统计。
- 审核列表按“套次 → 题型 → 原题号”显示。筛选不重新编号；勾选、重试、编辑与审核仍使用题目 ID。
- 收起审核列表时完全隐藏题号及分组，保留展开按钮。批量选择明确显示卷别，避免多套试卷的相同题号混淆。

## 历史数据与导出

- 历史批次的原题号、题目 ID、审核记录和重试依据不改写。
- 使用旧计划创建新批次时，派生新版分组计划；兼容的旧智能计划直接复用规划内容，不增加一次 AI 规划。旧计划保留。
- 导出只使用当前导出门禁允许的题目；每套试卷按题型排序后重新从 1 连续编号。删题后的空号被压缩，试卷和答案采用同一映射。
- 题型大题标题显示题数和总分；仅当组内分值相同时显示“每题 X 分”。审批记录同时保留原题号与导出题号。
- 旧下载文件不变，需重新导出才能应用新排版。

## 验证

- 后端：`mvn test`。`QuestionTypeGroupingTests` 覆盖题位整体移动、分值/题量不变、历史计划保留和升级不重复调用模型；`ExamProjectExportFormatTests` 核对三种格式的分组、连续编号、答案匹配及审计映射。
- 前端：`npm run test:question-grouping`、`npm run build`。
- 开发环境隔离样例：`http://127.0.0.1:5173/tests/question-grouping.html`。复用正式页面组件，仅模拟审核请求，不联网、不修改真实题库。可检查跨卷勾选、批量通过、隐藏题号栏及等待生成的题位。
