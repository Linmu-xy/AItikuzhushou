# 命题项目第 10 阶段：Word / PDF 交付与导出质量门禁

## 本阶段已完成

- 在原有 Excel 和附件 ZIP 交付之外，新增可选择的 Word、PDF 交付：
  - `PAPER_DOCX` / `PAPER_PDF`：按变式卷输出题目，保留题型、难度、分值、题干和选项。
  - `ANSWER_DOCX` / `ANSWER_PDF`：在试卷内容基础上输出答案、解析、评分细则、资料来源、题目版本和审核人。
  - `APPROVAL_DOCX` / `APPROVAL_PDF`：输出审批栏、逐题审核记录和资料版本清单。
- Word 输出使用固定 A4 页尺寸、中文字体和通用段落版式；PDF 输出嵌入中文字体，支持跨页、中文文本搜索和留档打印。
- 新增服务端导出后质量门禁：
  - Word 重新打开后检查项目名称、题目内容和文档非空。
  - PDF 重新打开后检查页数、项目名称和题目内容。
  - 检查失败会使当前导出任务进入 `FAILED`，不会产生可下载的伪成功制品。
- PDF 字体支持 `APP_EXPORT_PDF_FONT_PATH` 配置；Windows 默认优先使用 `simhei.ttf`，再尝试其他中文字体路径。
- 前端第 09 步增加 Word / PDF 选项，保留原有 Excel / ZIP 选项和默认选择；原有题库导出接口未修改。
- 未指定 `outputTypes` 的旧项目导出请求仍沿用第 9 阶段的四类默认输出，Word / PDF 仅在明确勾选或传入时生成。
- 增加 Word / PDF 生成与可读性测试，验证中文项目名称和题干能够被重新读取。

## 版式边界

本阶段先提供稳定的通用 Word / PDF 交付版式。资料目录中的旧版 `.doc` 样题模板会继续作为资料来源、模板版本和附件被记录并可打包，但暂不直接把旧 `.doc` 的复杂合并单元格、页眉页脚和坐标字段映射到新文档。这样可以避免模板字段不一致导致错位或内容截断。

后续如需完全复刻学校模板，可在此基础上增加“模板字段映射与版本适配”配置，并在导出前增加模板渲染预览和人工确认。
