## 三、哪些消耗可以优化

### 优先级P0：消除“花完思考预算却没有答案”

现有OpenAssessmentService把作者和盲解硬编码为high，即使generationMode=FAST也如此；JUDGE虽标low，本次仍产生4,972个思考Token。单靠给模式起名或设置low不能认定成本已降低。

建议按风险选择推理强度：普通概念与常规题用紧凑低思考，复杂推导、歧义冲突和专业高风险题再升级。保留所有题的正确性与材料完整性检查，不以减少审查换低价。

记录finish_reason，区分格式错误、截断、空正文与语义不合格。真正截断不应交给JSON修复器猜补；空盲解可以进行一次受控、简短且仍不看作者答案的重新作答，仍失败则待审。不要原参数原样重复高思考，也不要粗暴降低max_tokens使截断更频繁。

### 优先级P1：减少计算工具前后的整题重复推理

第2题作者先用了8,840输出Token返回一个计算动作，收到结果后又用了5,136输出Token；盲解也经历两个回合。工具计算本身很便宜，重新进入完整推理才贵。

可试验让作者/盲解在一个结构化结果中给出变量定义、公式、代入式和最终结论，由本地计算器自动校验；只有计算不一致或公式语义有争议时才追加模型回合。数学计算可由程序核验，公式适用性、单位和假设仍由独立审查负责。不能把作者的答案或公式喂给盲解者冒充独立验证。

对确需检索的任务，保留可继续的工具对话或最小任务状态；当前每次都重发初始题目和累计工具结果，缺少连续工作状态。改为原生工具调用是否更省Token还需要同输入对照，不能预先保证。

### 优先级P1：缓存资料理解，而非每次重读

本次图像概览3次共4,864 Token；规划另用8,801 Token。相同资料的原图观察、文档归纳和领域画像可按用户权限、文档版本、OCR/校对版本、模型与提示版本缓存。要求变化时重做题位规划，不能不加区分复用整份旧试卷计划。

长文档分段归纳也有同类复用空间，但本批没有触发该阶段，不能把它算成本次已测浪费。

### 优先级P2：压缩重复字段与无关审查输出

本批作者同时写answer、analysis、scoringRubric和内部basis，内容多次重复，审查又全部读取。保留明确答案、关键依据和可执行评分即可，避免反复写概念综述；单选不用长评分细则，非选择题审查不用A/B/C/D检查结果。

这些是可以精简的部分，但本批输入仅占总Token约22.75%，优先级低于失败调用和反复高思考。不能为省字段删掉必要的评分依据或正确性核验。

### 不应省掉的部分

- 决定答案的题面条件、真实图像、公式定义及单位。
- 独立作答隔离，以及有分歧时的核查。
- 标准/时效事实在需要时的权威检索。
- 必要评分点和可接受替代答案。
- 人工终审与未通过不批准的机制。

## 四、题质还能怎样提升

1. **先形成可验证的问题，再写长篇答案。** 轻量方案只说明能力、作答表现、适用题型，不预设正确结论。几何题验证尺寸闭合、干涉与投影；计算题检查对象、基准、单位和公式定义。模型仍可以自由迁移，不受某段知识库文本限制。
2. **让盲解异议必须闭合。** 开放题允许多解，不应一见ambiguities就机械拒绝；但影响判分的歧义必须标明属于题干已覆盖、评分已接受、需要补条件或尚未解决，并指出对应文字。审查不能靠替题干补假设来判PASS。本次第2题适合局部补基准，而不是整题重写。
3. **评分看可观察能力，不看是否复述作者方案。** 对每个得分点说明什么表现可得分、什么合理替代可得分；总分程序核验，专业可行性语义审核。避免“没选推荐方案最多4分”之类无充分依据的限分。
4. **图形学科用可校验的小图。** 可以使用知识库原图，也可用参数化SVG/CAD生成自足新图；不要把能力开放误解为只能用大段文字编造几何。图像和尺寸需要交叉检查，不能用精美但尺寸不可靠的图片提高表面观感。
5. **控制考核负担，不堆任务。** 一题聚焦一至两个关键决策，删掉不参与判断的数字和背景。难度来自概念迁移、条件权衡与错误模型辨别，不来自长题干或术语数量。客观题的干扰项应反映真实误解。
6. **用教师反馈校准，而不是继续堆提示词。** 建立小规模跨题型教师验收集，记录错误原因和必要修改。优先对照“现流程”和“精简分级流程”，固定资料、能力目标、题型与难度，比较首次可接受率、关键错误、人工修改时间、每道最终接受题Token和端到端耗时。

## 五、建议的新调用结构（尚未实施）

资料版本画像缓存 → 轻量能力规划 → 按题型/风险命题 → 本地结构/算术检查 → 紧凑独立作答与审查 → 仅有缺陷处修订一次 → 人工终审。

普通题可试验低思考或小批生成；复杂计算/图形/综合题保留深度解题；有真实分歧时升级核验。共享资料与确定的外部事实可复用，作者答案不能泄露给盲解。

推荐先优化P0，再对照计算工具回合与异议闭合；不急于大规模换模型、不一次生成数百道来试错、不取消质量门禁。
