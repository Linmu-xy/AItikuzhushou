# 资料智能组卷：第 2 阶段开发说明

本阶段在现有工作台中新增“资料组卷”入口，负责模型/工程图资料的接收、分析状态查看、三维预览和事实人工确认。原有知识库、职业标准、细目表、题库任务和导入导出流程未改动。

## 开发环境

前端新增 `three` 和 `@types/three`，三维查看器通过动态导入拆分为独立 chunk。首次安装或切换机器时执行：

```powershell
cd D:\code\tikuzhushou\frontend
pnpm install --frozen-lockfile
pnpm run build
```

本地开发仍使用原有启动方式：后端 `8080`、前端 `4173`。页面需要登录后，在左侧“资料 → 资料组卷”进入。

## 本阶段可用流程

1. 选择知识库，上传 STEP、STP、X_T、PRT、DWG、DXF、PDF、STL 或 OBJ。
2. 选中资料并提交分析，前端轮询 `CAD_ANALYSIS` 工作流任务。
3. STEP/STP 分析完成后可旋转、缩放三维 OBJ 预览；工程图和暂不支持解析的格式保留原文件并展示状态。
4. 查看右侧事实的 JSON 值、解析来源和置信度。
5. 教师逐条确认事实；只有“确认并允许出题”的事实会被标记为后续组卷可用。

## 生产安全边界

- 浏览器页面不会直接读取本地路径，资料经后端上传、权限校验和工作流分析。
- 新增事实默认 `verified=false`、`usableForGeneration=false`，不能绕过人工确认进入出题。
- 三维预览使用动态 chunk，不会把 Three.js 首屏加载到原有页面。
- 下载原文件仍受现有知识库权限和登录会话保护。

本阶段暂不生成试卷、答案、审批表或压缩包；这些属于后续组卷设计、题目审核和交付阶段。
