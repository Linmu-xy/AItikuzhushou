# MVP 验收评分标准

| 项目 | 通过条件 | 自动检查 |
| --- | --- | --- |
| 文档入库 | 文件类型、大小与归属知识库合法 | 是 |
| 文本解析 | 可提取文本或明确标记 `OCR_REQUIRED` | 是 |
| 职业标准 | 人工确认后才可生成 | 是 |
| 数量控制 | 实际题数与细目表目标一致 | 是 |
| 题型覆盖 | 输出题型与细目表分配一致 | 是 |
| 考点映射 | 每题都有来源考点 | 是 |
| 去重 | 规范化题干不重复；发现时告警 | 是 |
| 导出 | XLSX 包含序号、题型、考点、难度、题干、选项、答案、解析 | 是 |
| 内容正确性 | 与原文事实一致、答案合理、难度适配 | 人工抽检 / 后续模型复核 |

默认放行规则：数量误差、字段缺失、考点缺失任一失败时，不得作为验收通过结果；重复题以告警形式呈现，供人工处理。
