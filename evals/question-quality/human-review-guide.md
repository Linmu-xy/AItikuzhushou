# 教师盲审口径

先只看考生题面独立作答，再看答案和评分；不要先看模型自评分或版本标签。对比版本时随机顺序，避免“新版应该更好”的预期。

| 维度 | 通过的可观察证据 | 需要修改的例子 |
| --- | --- | --- |
| 答案正确 | 在题干给定条件下，原理、计算、单位和结论成立 | 换了百分比分母；将制品尺寸当成型腔尺寸；决定得分的舍入值错误 |
| 条件充分 | 考生无需猜测隐藏假设；有意开放的范围可解释 | 未指定截面却要求唯一数值；没有图却要求读取图面细节 |
| 目标匹配 | 作答确实展示题位所要考查的能力 | 目标是工艺判断，实际只考一个无关术语 |
| 考核价值 | 学得扎实者能用知识区分方案、解释机制或完成任务 | 应用题在材料里写出全部结论，仅需换词复述；靠最长选项猜中 |
| 干扰项质量 | 错误项代表可解释的典型误解，在当前条件下确实错误 | 两项同时正确；三个荒谬项衬托正确项；选项不同维度 |
| 评分公平 | 得分表现可观察、合计正确，合理替代方法有得分条件 | 推荐方法被当成唯一方法；仅写“回答较好”；同一传递错误反复扣分 |
| 组卷多样性 | 同批题测不同表现或新迁移，非换数值重复 | 案例题、计算题、综合题都重复同一个收缩率计算 |

## 判定边界

- 答案错误、决定结论的缺条件、评分拒绝合理答案，不能用其他维度高分抵消。
- 不把“题干短”“判断题”“知识库没有原句”当成质量差的理由；依据目标判断基础理解是否有考核价值。
- 不强求每题跨多个考点或套职业故事；必要复杂度比篇幅重要。
- 不涉及选项时 `distractorQuality=NOT_APPLICABLE`，未检查的维度必须 `NOT_REVIEWED`，不要补成 PASS。
- 专业标准/版本事实须核对适用的一手资料，但考生端不强制展示知识库出处。
- `accepted` 仅由人工验收填写；AI 审查状态单独保留。没有验收题时，不计算“每道验收题 token”，也不拿除数1替代。

## 样本组织

按学科、题型、难度分层；为每个领域积累至少30道专家标注作为起点。改提示词用开发集，选方案用验证集，最终报告用未参与调参的保留集。当前41项工程案例不是这份专业题集。

单次3道CAD实测只能发现具体问题，不能估计总体正确率或证明统计意义的区分度；真实区分度需要考生作答数据。
